# Earthforce capital variety

The existing class library already contained Hyperion, Omega, Nova, Avenger, Warlock and Poseidon. However, Avenger, Warlock and Poseidon were still using small construction-unit lengths (roughly 100–300) alongside kilometre-scale hulls. The class library now normalizes their delivered lengths to 1400, 1992 and 1300 game metres respectively, so their silhouettes participate visibly in the capital line. These are artistic game scale choices, not a claim that every value is settled screen canon.

Every capital tier below the station crown can choose from all six classes using seeded random selection. A rare Explorer survey hull joins the roster: open truss, separated engine raft, transverse habitat arms and tanks. The station crown remains Babylon 5. Nova now has a broad engine transom, four large bells and connected outboard batteries. Existing individual propulsion and role refits still apply. The model study includes all nine Earthforce classes.
