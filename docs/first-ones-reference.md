# First Ones: visual and weapon pass

Eight original procedural reconstructions, informed by these references:

- [Screen images of the ancient ships](https://www.babylon5.sk/lode/ostatne-lode-prvych/): radial Walker dish, four-finned volcanic vessel, collector globe and three-arm convergence vessel.
- [Fan model archive](https://www.ultradrive.com/b5_3d_index.htm): Walker, Volcano and Vorlon models listed in older 3DS/Lightwave formats. Used as a reference index; no third-party model files imported.
- [Starship Modeler reference gallery](https://www.starshipmodeler.com/b5/b5tech.htm): Vorlon transport front, rear and side views.
- [Agents of Gaming miniatures](https://www.agentsofgaming.com/b5wminis.htm): licensed ancient fleet silhouettes.

The existing fleet uses the Kirishiac globe / Mindrider volcanic identification; licensed games disagree on these names. Lorien's weapon and the exaggerated discharge mechanics are game inventions, not claims about on-screen capabilities. The Hand servitor remains in the existing crossover roster.

| Vessel | Geometry | Weapon interpretation |
|---|---|---|
| Traveller | Rimmed radial dish, curved ribs, aperture | Rift beam and secondary lightning |
| Lordship | Ribbed globe, collector petals | Inward gravity collapse |
| Thoughtforce | Volcanic crown, four buttresses | Radial thought-wave discharge |
| Triumviron | Three curved arms around open space | Three-source convergence beam |
| Dark Knife | Thin swept blade, layered ribs | Brief, broad cutting plane |
| Lorien | Swept organic body and fins | Long, luminous First Light beam |
| Vorlon transport | Ribbed bulb, paired eyes, trailing petals | Braided living lightning |
| Hand servitor | Branching crystalline arms | Fracture spreading from the victim |

Charges last 3–4.6 seconds. One ancient weapon reserves the stage through its 2.6-second aftermath. Damage is applied once; visual rays use the existing batched coherent renderer. No victim teleportation or permanent speed penalties. Arrivals are staggered 11.5 seconds apart and named only in the Action caption.
